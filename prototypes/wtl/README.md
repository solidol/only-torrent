# Only Torrent — WTL prototype

Окремий прототип головного вікна для оцінки MSVC + WTL + Win32.
Власний код — BSD-3-Clause, оригінальний WTL — MS-PL.

## Збирання

Потрібні Visual Studio 2022 C++ tools, ATL, Windows SDK та CMake.

```powershell
powershell -ExecutionPolicy Bypass -File tools/build-wtl-prototype.ps1 -FetchWtl
```

Наступні збирання без мережі: та сама команда без `-FetchWtl`.
WTL завантажується лише явно, в ігнорований кеш `deps/wtl-10.01`. Ревізія
офіційного Git зафіксована в dependencies.json; локальні зміни заборонені.
Скрипт не запускає програму й не виконує тести.

Вихід: `build/wtl-prototype/Release/otorrent-wtl-prototype.exe`.
Visual Studio solution: `build/wtl-prototype/OnlyTorrentWtlPrototype.sln`.
Можна також відкрити цю папку як CMake-проєкт і задати WTL_ROOT.
CRT статично скомпонований (/MT), окремої DLL WTL/VCL/Qt немає.

## Що можна оцінити

- Системні меню, панель команд, дерево категорій, таблиця та status bar.
- Два перетягувані розділювачі й панель відомостей із вкладками.
- Віртуальний список LVS_OWNERDATA, сортування заголовками й Ctrl/Shift-виділення.
- Пуск, пауза, перевірка та видалення лише синтетичних задач; додавання деморядка.
- Непослідовна карта блоків («забір») у колонці готовності; групування за шириною.
- F5: необов’язкова анімація демоданих. За замовчуванням немає timer polling.
- Системні кольори, Common Controls v6, Segoe UI, обробка WM_DPICHANGED.
- Діалог відомостей — текстовий ресурс resources/Prototype.rc.in. CMake створює
  Prototype.rc у build; джерело для редагування — .rc.in. Native Dialog Editor
  можна використати для перегляду/редагування з подальшим перенесенням змін.

## Структура

| Файл | Призначення |
| --- | --- |
| src/Main.cpp | Запуск, COM, WTL module і message loop |
| src/Ot.MainFrame.* | Win32-контроли, компонування, події, проєкція видимих рядків |
| src/Ot.DemoModel.* | Дані й демонстраційні команди; без залежностей від WTL/Win32 |
| src/Ot.DetailsPane.* | Ресурсний діалог нижньої панелі |
| src/Ot.FencePainter.* | Малювання карти блоків через GDI |
| resources/ | Меню, accelerators, діалог, manifest та version info |

## Межі

Це UI-прототип, а не порт торрент-клієнта. Відсутні libtorrent, профіль,
SQLite, INI, JSON-локалізація, HTTP, асоціації, трей та апдейтер. Назви,
швидкості й блоки — синтетичні; не можна відкривати справжні торренти.
Вкладки нижньої панелі показують текстові приклади, без графіка швидкості.
Закриття завершує лише прототип. Мінімізація стандартна, в taskbar.
Жодного файлу користувача або налаштування Only Torrent не читає й не змінює.

Ціль компіляції — Windows 7 API / x64. Робота на Windows 7 і поведінка DPI
потребують окремої перевірки. Розмір цього GUI не можна порівнювати з повним
клієнтом як доказ виграшу: тут немає рушія, сховища й більшості функцій.
