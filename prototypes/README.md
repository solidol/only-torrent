# Прототипи інтерфейсу Only Torrent

| Варіант | Код | Дизайн | Стан |
| --- | --- | --- | --- |
| [Win32 + WTL](wtl/README.md) | MSVC / WTL / Win32 | Ресурс .rc.in і код компонування | Release/x64 зібрано; програму й тести не запускали |

Усі використовують спільну демомодель із wtl/src/Ot.DemoModel.* та синтетичні
дані. Вони не підключають торрент-рушій і не змінюють профіль основної програми.
Збирання й перевірки виконуються лише на явну команду користувача.
