# Only Torrent


Version: 0.3.6.32

A lightweight, open-source BitTorrent client for Windows x64. Supports torrent files, HTTP and magnet links, task import, watched folders, file verification and download recovery.

Powered by libtorrent with a Delphi / VCL interface. BSD 3-Clause license.

Версія: 0.3.6.32
