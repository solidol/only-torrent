# Ярлики й видалення даних

MSI дозволяє вибрати компоненти: обов’язкову програму, ярлик меню «Пуск»
(типово ввімкнений) і ярлик робочого столу (типово вимкнений).
Папка встановлення змінюється на сторінці вибору компонентів.
Для тихої інсталяції можна задати `ADDLOCAL=MainFeature,StartMenuFeature,DesktopFeature`;
непотрібні компоненти виключаються через `REMOVE=StartMenuFeature,DesktopFeature`.

**Параметри Windows → Програми → Only Torrent → Видалити** відкриває діалог:

- не видаляти профілі (початковий вибір);
- очистити профіль поточного Windows-користувача;
- очистити профілі всіх користувачів.

Використовується SID користувача, який запустив деінсталяцію, навіть якщо UAC
працює з іншим обліковим записом адміністратора. Профілі визначаються за
Windows ProfileList; системні й службові профілі виключені.
Підтримано стандартну папку Roaming та локальне перенаправлення в межах
відповідної папки Windows-профілю. Перенаправлення за її межі не очищуються,
щоб користувацьке налаштування AppData не дозволяло видалити чужі дані.

Службовий застосунок працює з тимчасової копії, штатно закриває клієнт і
видаляє MSI-продукт. Очищення профілів починається **тільки після успіху MSI**.
При помилці MSI профілі не змінюються. Недоступні, активні або перенаправлені
через reparse points/UNC профілі зберігаються з повідомленням про неповне очищення.

Видаляються лише `settings.ini`, `tasks.db` із WAL/SHM та службові файли
`Torrents/<info-hash>.torrent`. Невідомі файли, завантаження й інші документи,
зокрема всередині профілю, не обходяться рекурсивно й не видаляються.
Службові torrent-файли поза профілем також залишаються. Порожня папка
профілю прибирається. Запис автозавантаження поточного користувача видаляється,
тільки якщо команда вказує на видалену інсталяцію.

У Windows показується один запис Only Torrent із повною версією. Нативний
MSI-запис прихований, але Windows Installer продовжує реєструвати продукт,
підтримувати ремонт і транзакційне оновлення. Прямий `msiexec /x {ProductCode}`
або видалення старої MSI-версії під час оновлення **завжди зберігає профілі**.
Для вибору очищення слід використовувати діалог видалення через Windows.
Автоматизований запуск діалогу може зафіксувати збереження профілів прапорцем
`--keep-profiles`; тоді вибір очищення заблокований також на рівні коду.
