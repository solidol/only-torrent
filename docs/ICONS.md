# Значки Only Torrent

Інтерфейс використовує вибрані Microsoft Fluent System Icons (MIT), джерела зафіксовані commit/SHA-256 у resources/icons/fluent/manifest.json. Колірні варіанти й SHA-256 готових PNG — generated.json у тій самій папці; правила повторної підготовки — README.md.

ImageCollectionMain містить PNG для світлої/темної тем у розмірах 20, 24, 32, 40, 48, 64. VirtualImageListMain — єдиний набір індексів для панелі, дерев, меню, таблиці й заголовків; DPI масштабує штатна VCL. Для інтерполяції задано WIC Fant без вимоги нового SVG-рушія. У DFM збережені всі компоненти та зображення; при перемиканні теми змінюються лише посилання на джерела колекції.

Застосунок не малює значки геометричними примітивами й не потребує SVG-парсера, Node, resvg, шрифтів значків або зовнішніх PNG. Ці інструменти потрібні тільки для явно запущеної підготовки ресурсів; звичайний Delphi build використовує готовий DFM. Попередній код малювання замінений таблицею станів у Ot.StatusIcons.pas. Тестові preview-хелпери винесено до tests/Ot.IconPreview.pas.

Збережені play/pause першої колонки та бордове завантаження в колонці стану. Візуальний огляд готових ресурсів — resources/icons/fluent/preview.png. Новий build зібрано без запуску застосунку й тестів; фактичне відображення форм у цьому білді не перевірялося. Windows 7 не перевірялася.
