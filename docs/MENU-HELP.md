# Дублікати, меню та інформація про програму

Повторне ручне відкриття `.torrent` перевіряється за info-hash, а не назвою файла.
Задача виділяється у списку; користувач отримує пропозицію додати нові трекери.
«Ні» не змінює список, «Так» об'єднує адреси без повторів. Регістр шляху та
passkey зберігається. Список фіксується в JSON і передається поточній сесії
без зміни стану паузи, пріоритетів, шляхів або результату перевірки файлів.
Якщо нових адрес немає, показується інформаційне повідомлення.
Автопідхват не відкриває модальних повідомлень і самостійно не змінює трекери.

Використовується наявний C ABI `lt_apply_magnet` із запитами, які містять лише
info-hash і трекери. DHT та підключення до сторонніх peer hints не вмикаються.
Великі списки діляться на запити до 32768 байтів. DLL не змінювалися.

## Гарячі клавіші

Літери однакові в обох мовах інтерфейсу; Alt-меню обробляє латинські virtual keys
також при українській розкладці клавіатури.

| Дія | Комбінація |
| --- | --- |
| Файл / Налаштування / Вигляд / Довідка | Alt+F / Alt+S / Alt+V / Alt+H |
| Додати torrent / посилання | Ctrl+O / Ctrl+U |
| Імпорт задач | Ctrl+Shift+I |
| Параметри / оновити | Ctrl+P / Ctrl+Shift+U |
| Темна тема | Ctrl+Shift+D |
| Панель інструментів / бічна панель / відомості | Ctrl+Shift+T / Ctrl+B / Ctrl+D |
| Про програму | Shift+F1 або Alt+H, A |
| Вихід | Alt+F4 |

Пункт «Довідка» всередині однойменного меню поки неактивний.

## Текст «Про програму»

Джерело коротких описів українською й англійською — кореневий `ABOUT.md`.
`tools/version.ps1` оновлює обидва рядки версії разом із VERSIONINFO.
Форма читає мовний розділ із `ABOUT.md` поруч із EXE, якщо цей файл наявний;
інакше — з пакетного `README.md`. Простий текст без мовних заголовків також
можна використати. Відсутній або некоректний файл не перешкоджає відкриттю форми.
Розділи можуть позначатися заголовками або рядками `Version:` / `Версія:`;
порядок мов у файлі довільний.

Під час збирання `ABOUT.md` копіюється в `README.md` runtime-папки. Це зберігає
сумісність ZIP із whitelist попереднього апдейтера: нових імен файлів у пакеті
немає. README репозиторію залишається технічною документацією. MSI і portable
ZIP отримують той самий опис; шляхи визначаються від EXE, а не поточної папки.
