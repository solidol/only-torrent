# Папки завантаження

Для нового профілю типова папка — Windows Downloads користувача
(`TPath.GetDownloadsPath`, із підтримкою перенаправленої папки Windows).
Другий початковий варіант — `C:\Downloads`; він також є резервним шляхом,
якщо Windows не повернула папку Downloads. Наявна конфігурація зберігається.

Діалог додавання дозволяє ввести шлях вручну, вибрати папку через кнопку `…`
або вибрати один із останніх шляхів у випадному списку. Після підтвердження
вибору остання папка стає поточною і першою в історії; скасування не записує
новий шлях. Вибір через налаштування також оновлює історію.

До 10 шляхів зберігаються в `[DownloadFolders]` INI профілю: `Count` і
`Folder0`…`Folder9`. Дублікати порівнюються без урахування регістру, після
нормалізації абсолютного шляху, `/`, `..` та кінцевого роздільника.
Наявний шлях переноситься на початок, одинадцятий найстаріший витісняється.
Під час завантаження налаштувань папки не створюються автоматично.
