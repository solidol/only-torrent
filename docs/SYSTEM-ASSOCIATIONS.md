# Системні асоціації

Налаштування → Системні асоціації: позначити `.torrent` та/або `magnet`,
натиснути «Зареєструвати вибрані типи». Це окрема негайна дія; «Застосувати»
чи «OK» самі реєстр не змінюють. «Скасувати» не скасовує вже виконану реєстрацію.

Реєстрація записується в HKCU: Classes, RegisteredApplications і
Software\Only Torrent\Capabilities. Прав адміністратора не потрібно.
Windows UserChoice та чинний обробник іншого клієнта не перезаписуються.
Якщо асоціація вже зайнята, відкрити «Програми за замовчуванням Windows»
і вибрати Only Torrent для `.torrent` та MAGNET. На Windows 7 відкривається
Default Programs, на Windows 10/11 — Default Apps.

Натискання справжнього `magnet:?xt=...` посилання на сайті викликає системний
обробник. Браузер може попросити дозвіл відкрити зовнішній застосунок.
Програма не змінює дозволів браузера. Magnet передається без декодування всього
URI, щоб зберегти вкладені percent-encoded адреси трекерів і назву.
Отримання метаданих має прогрес, скасування та наявний таймаут; після нього
відкривається стандартний діалог додавання з вибором файлів і папки.
Скасування не додає задачу. Звичайні HTTP/HTTPS-посилання залишаються браузеру.

Команда обробника: `"<повний шлях до otorrent.exe>" --open "%1"`.
Прямий запуск також підтримує аргументи `.torrent` та magnet.
Приймається до 32 запитів; кожен — до 32768 UTF-16 символів, без NUL/CR/LF.
Шлях torrent-файла перетворюється на абсолютний у процесі-відправнику.

Один екземпляр на профіль і Windows-сеанс: mutex та приховане IPC-вікно.
Другий процес передає запит через обмежений WM_COPYDATA і завершується,
не відкриваючи сховища SQLite. Обробник IPC лише копіює дані в чергу.
Головне вікно обробляє чергу поза іншими модальними діалогами й відновлюється
з трея. Звичайний повторний запуск без аргументів також показує відкрите вікно.
Різні OT_PROFILE_DIR ізольовані. Під час зависання чи недоступності першого
процесу показується помилка з обмеженим очікуванням, другий рушій не запускається.

Запускати програму без підвищення прав: Windows UIPI може блокувати передавання
з браузера до процесу адміністратора. Після переміщення portable EXE повторити
реєстрацію з нового місця. Обробники посилаються на конкретний шлях EXE.

## Ручна перевірка за окремим дозволом

- Зареєструвати обидва типи у тестовому обліковому записі Windows.
- Перевірити збереження чинних асоціацій іншого клієнта; вибрати Only Torrent
  стандартними засобами Windows.
- Відкрити `.torrent` із Unicode-шляхом і пробілами при закритій програмі.
- Натиснути magnet на HTML-сторінці при закритій програмі, відкритому вікні,
  мінімізації в трей і вже відкритому діалозі додавання.
- Перевірити чергу, скасування, дублікати info-hash, відсутній файл,
  некоректний magnet та повторний запуск без аргументів.
- Перевірити відмову передавання між різними рівнями привілеїв без зависання.
- Повторити на Windows 7 SP1 і Windows 10/11.
