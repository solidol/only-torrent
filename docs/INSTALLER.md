# MSI та переносний ZIP

Кожний новий реліз публікує `Only-Torrent-<version>-Win64.zip` і
`Only-Torrent-<version>-Win64.msi`, кожний із SHA-256.

MSI встановлює програму для всіх користувачів, типово в
`C:\Program Files\Only Torrent`, і створює ярлик у меню «Пуск».
Папку можна змінити у майстрі або параметром `INSTALLFOLDER` у msiexec.
Останній шлях запам’ятовується в HKLM\Software\Only Torrent.
Шляхи ресурсів програми визначаються від EXE, не від поточної робочої папки.

Профіль `%APPDATA%\Only Torrent` (INI, tasks.db, Torrents та інші дані)
не належить MSI. Перевстановлення, оновлення й видалення програми його не
видаляють: програма того самого Windows-користувача відкриває наявний профіль.
Старі профілі qsTorrent не мігруються. `OT_PROFILE_DIR` призначений для
ізольованого профілю, зокрема тестів.

При запуску апдейтера з папки без прав запису запитується UAC. Сам клієнт
не потребує запуску від адміністратора. Установник не запускає клієнт
автоматично під обліковим записом адміністратора.

Збирання: WiX 3.14.1, отриманий явно через `tools/fetch-wix.ps1` з офіційного
GitHub; архів зафіксовано SHA-256. `tools/build-release.ps1` збирає обидва
формати. `tools/build-msi.ps1 -PackageFolder <stage>` може повторно запакувати
вже підготовлений комплект. Завантаження WiX не є частиною звичайного build.

MSI порівнює три поля версії: використовується `Major.Minor.Build`, де Build
наскрізний. Повна версія `Major.Minor.Release.Build` лишається в EXE, JSON,
назві MSI й описі пакета. UpgradeCode сталий; нові MSI замінюють попередні
транзакційно, із відкатом Windows Installer у разі невдачі.

Інтерфейс установника наразі англійською; мови клієнта залишаються незмінними.
