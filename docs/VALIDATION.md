# Результати перевірки

Дата: 2026-11-13.

## Збирання

- qsbridge.dll та оригінальна torrent-rasterbar.dll: Visual Studio 2022, Release / x64, спільний CRT `/MD`.
- EXE й DLL зібрані для AMD64. На етапі відокремлення після перезбирання моста SHA-256 EXE та оригінальної DLL залишилися незмінними; тодішні DFM і PNG карти блоків збігалися з початковими. Доказ цього етапу: build/separation-proof.txt. На етапі P0 додано мову та папку метаданих у налаштуваннях; візуальний дизайн решти форм збережено.
- У фінальному EXE перевірено вбудований manifest Common Controls v6 / Windows 7. Прихований запуск досяг GUI message loop без помилки.
- qstorrent.exe: Delphi 13 Community Edition, Release / Windows 64-bit, через IDE AutoBuild. Командний dcc64 у CE недоступний; штатне `bds.exe qstorrent.dpr -b -ns` працює.
- Окремий QsUiSmoke.exe компілює й завантажує всі три DFM-форми. Українські рядки перевіряються порівнянням зі значеннями Unicode; джерела Pascal/DFM збережені в UTF-8 із BOM.

## Автоматичні перевірки

Перехід на готові DLL перевірено в `build/binary-only-project`: у копії немає `deps`, `native`, SDK чи старих результатів збирання. Успішно зібрано EXE, `QsCoreTests` і `QsUiSmoke`; післязбиральна команда IDE скопіювала runtime. У цій копії пройшли Core/UI, separation, engine smoke та пакування в окрему папку. Джерела сторонніх бібліотек для цих перевірок не завантажувалися. `tests/separation.py` перевіряє DLL за зафіксованим `third_party/bin/Win64/runtime.json` і більше не читає SDK.

Знімки build/ui-*.png містять синтетичні дані, крім ui-add-local-torrent.png — він показує метадані справжнього .torrent із Downloads без запуску завдання. Малювання «забору» перевіряється окремим знімком ui-block-fence.png і порівнянням пікселів порожньої та заповненої смужок. Це позаекранні контрольні малюнки, а не підтвердження мережевого завантаження. Мережевий тест окремий і порівнює фактичні байти. Частина native-елементів, наприклад заголовки списків або внутрішній edit комбобокса, може не потрапляти в PaintTo-знімок; їхні дані перевіряються також через властивості контролів.

## Що залишається перевірити

Windows 7 SP1 x64, публічні UDP/HTTP-трекери, NAT, тривале навантаження й великі набори файлів. Немає вимірювань пропускної здатності або порівнянь швидкодії з іншими клієнтами. Автоматична темна тема Windows та HTTPS-трекери не реалізовані. Відновлення списку й fast-resume реалізовано та перевірено в ізольованих профілях; тест на перервану SQLite-транзакцію не є випробуванням фізичного знеструмлення диска.
