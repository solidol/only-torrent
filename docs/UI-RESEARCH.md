# Аналіз інтерфейсу µTorrent і рішення для qsTorrent

Перевірено 2026-11-13. Наданий користувачем скриншот показує **µTorrent 1.6**; його використано як орієнтир щільності та компонування. Він не є знімком 2.x або 3.x. Колір рамки на ньому належить оформленню Windows XP, а не власній темі qsTorrent.

| Частина | µTorrent 2.x | µTorrent 3.x | Рішення для qsTorrent |
|---|---|---|---|
| Основне вікно | Панель команд, категорії зліва, таблиця, нижні відомості | Зберігає основний сценарій, розширює функції та оформлення | Щільний інтерфейс зі стандартних VCL-контролів |
| Додавання | Папка, початкові параметри, список файлів | Пізні версії мають окремі параметри імені й створення підпапки | Папка, прапорці файлів, вибраний обсяг, вільне місце, початковий стан |
| Налаштування | Групування за тематичними категоріями | Категорії розширені додатковими можливостями | Дерево зліва, сторінки справа, OK / Скасувати / Застосувати |
| Прогрес | Компактний показ у таблиці та відомостях | Зберігає показ стану завдання | Прогресбар у колонці та окремий індикатор вибраного торрента |

Офіційні [примітки µTorrent 2.2](https://forum.utorrent.com/topic/65743-%C2%B5torrent-22-released/) описують новий формат оформлення, можливість повернути піктограми 2.0.4 та діалог додавання магнетів. Отже, навіть усередині 2.x оформлення відрізнялося; універсальної піксельної копії всіх випусків немає.

Архів [посібника 3.5.5: Add New Torrent](https://techshelps.github.io/utorrent-355-45852/html/AppendixA_04_01.html) описує папку, ім’я, підпапку, запуск, мітку, вибір файлів та підрахунок обсягу. Це джерело саме для пізньої гілки 3.x, а не доказ тотожності кожному випуску 3.0. У qsTorrent зараз реалізовано папку, вибір файлів, обсяг і запуск. Перейменування, черга та мітки не імітуються.

[Розділ Preferences](https://documentation.help/uTorrent/AppendixA_02.html) підтверджує тематичне групування параметрів і Ctrl+P. [Directories у посібнику 3.5.5](https://techshelps.github.io/utorrent-355-45852/html/AppendixA_02_03.html) пояснює зв’язок типової папки з показом діалогу додавання. Цей зв’язок реалізовано: коли діалог вимкнено, використовуються типова папка, всі файли та збережений початковий стан.

## Оформлення та поведінка

Увімкнена системна тема використовує Windows UxTheme, Explorer-оформлення списків і системний PROGRESS для індикаторів. Вимкнена тема прибирає тематизацію стандартних native-контролів. Кольори залишаються системними, без зашитого сірого фону таблиці. Це стандартне оформлення Win32/VCL, а не обіцянка автоматичної темної теми або Fluent/Acrylic.

Власні невеликі піктограми намальовано кодом; ресурси µTorrent не копіюються. Список використовує один малюнок прогресу на видиму комірку, а не окремий HWND на кожен торрент. Дані оновлюються раз на секунду; графік має обмежену історію. Шляхи та параметри зберігаються в UTF-8 INI в AppData.

## Межі цього етапу

Нижні вкладки: загальні відомості, файли з початковими пріоритетами, адреси трекерів із метаданих, графік швидкості та журнал. Статус відповіді кожного трекера ще не виводиться. Немає вигаданих значень доступності частин або списку пірів. DHT, проксі й веб-інтерфейс залишаються у попередньому плані; HTTP-сервер не запускається.
