# Аудит інтерфейсу й поведінки, 2026-11-16

Порядок: початковий загальний прохід на 0.3.4.25, пакет виправлень,
спільні регресійні проходи; повторні виправлення після невдалих перевірок.
Робочий профіль користувача не змінюється.

## Знайдені недоліки

| Недолік | Виправлення / рішення |
| --- | --- |
| Іконки toolbar зникають після зміни VCL style | Delphi 13 змінює Name разом із CollectionIndex. Збережено сталі імена virtual items, до яких прив'язані кнопки; піксельна перевірка панелі й 40 перевірок імен у двох темах |
| Перемикання теми з toolbar знищує handles усередині обробки натискання | Відкладений виклик після завершення native notification; окремий тест першого натискання без відкриття меню |
| MemoInfo перекриває легенду карти блоків | Розведено межі в DFM |
| Помилка відновлення задачі з недоступною папкою зберігається, але не показується у відомостях | Виводиться LastError, якщо стан — помилка і engine error порожній |
| Некоректне введення відкриває іншу сторінку налаштувань, не змінюючи виділення дерева | Синхронізація категорії з активною сторінкою перед повідомленням |
| Зміна мови не оновлює детальні списки вибраної задачі | Оновлення деталей після застосування налаштувань |
| 28 написів DFM не мали перекладів; існував помилковий ключ Columns.-1 | Доповнено обидва каталоги; перевірка всіх текстових DFM властивостей та компактних колонок |
| «Черга» у списку порядку означала лише номер файлу | Перейменовано «№»; справжнє керування порядком у P0 |
| Старий release_integration очікував видалені кнопки Check/Download/Install | Актуалізовано до одного Update; fixture не залежить від видаленого старого ZIP |

Початковий розширений аудит також показав втрату рядків у синтетичному тесті:
рядки були додані лише у VCL, без моделі задач. Це помилка fixture, а не втрата
реальних задач. Новий прохід використовує справжню відновлену задачу з копії
ізольованого Core-профілю. Перевірка помилки порту автоматично закриває власне
native повідомлення; жодні вікна користувацького застосунку не обробляються.

Початкові переприв'язки image list не усували причину й вилучені. Окремий
custom style hook не входить до фінального коду: достатньо збереження імен.
Знімки тимчасово піднімають лише власну тестову форму та перевіряють HWND
у точці захоплення, щоб стороннє активне вікно не давало хибного результату.
Стандартний UI smoke щоразу отримує новий профіль, а не залишки попередньої теми.

## Межі доступних функцій

Активних команд без обробника під час аудиту не виявлено. Нижче відділено
робочі дії від довідкових списків і явно запланованих функцій.

- Працюють: torrent/HTTP/magnet, вибір файлів і папки, MRU, локальні ліміти,
  послідовні частини, глобальні параметри, DHT enable, автопідхват,
  імпорт, пакетне видалення й recheck, сортування, теми, трей, асоціації,
  ручний апдейтер, MSI й вибір очищення профілів.
- Відомості видавця, web seeds та опис — read-only метадані, не редактор.
- Трекери — статичні адреси; live announce status відсутній.
- Довільний порядок / пріоритет файлів після додавання відсутній.
- Розділ «Наступні етапи» явно описує майбутні DHT/proxy/web можливості.
  Пріоритет і критерії завершення: [ROADMAP.md](ROADMAP.md).

## Обсяг перевірки

Core/UI, PAS/DFM, UTF-8/переклади, усі сторінки налаштувань та діалогу
додавання у двох темах при 96/144 DPI, реальний toolbar input, карта блоків,
HTTP tracker/peer transfer, uploaded total/resume, HTTP/HTTPS validation,
magnet із локальним піром, скасування, автопідхват, імпорт BitComet,
пакетні операції, restart/recovery, трей, updater detach/shutdown/restart,
rollback, асоціації в ізольованому реєстрі, MSI на копії з окремим ProductCode.

Артефакти: build/interface-audit.txt, build/audit-*.png,
build/interface-native.path, build/full-validation-*.json.

Це перевірки на доступній Windows x64, не сертифікація всіх ОС і пристроїв.
Windows 7/11 на окремих машинах, інший користувач у UAC, реальні збої живлення,
публічна DHT/трекери та браузерні defaults потребують окремого середовища.
Публічний magnet без аргументу не є автоматичним тестом; локальні сценарії
перевіряють метадані й передачу без сторонніх завантажень.
