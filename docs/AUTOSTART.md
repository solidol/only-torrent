# Запуск разом із Windows

Прапорець **Налаштування → Параметри → Інтерфейс → Запускати Only Torrent
разом із Windows** початково вимкнений. Зміна набуває чинності після
«Застосувати» або OK, скасування нічого не реєструє.

Використовується лише значення `Only Torrent` у HKCU\Software\Microsoft\Windows\CurrentVersion\Run.
Команда містить абсолютний шлях поточного EXE у лапках. Прав адміністратора
не потрібно, записи інших програм не змінюються. Прапорець відображає
фактичну реєстрацію для поточного EXE; копія стану зберігається в INI.
Запуск програми або читання конфігурації самі не вмикають автозавантаження.

Тести реєстрації перенаправляють HKCU в ізольовану тестову гілку процесу.
