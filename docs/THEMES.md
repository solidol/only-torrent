# Теми основного застосунку

- Кнопка на панелі інструментів і пункт **Вигляд → Темна тема** перемикають
  світлу й темну теми одразу, без перезапуску.
- Вибір зберігається як `Interface.DarkTheme` у `settings.ini`; початково — світла тема.
- Світла тема використовує системний стиль Windows. Параметр системного
  оформлення в налаштуваннях дозволяє обрати стандартні або класичні контролі
  саме для світлої теми.
- Темна тема використовує вбудований VCL-стиль Windows10Dark, спільний для форм
  основного застосунку, з м’якою палітрою `Ot.DarkPalette` за зразком поточної
  теми VS Code Blade Color / Dark+: фон `#1E1E1E`, панелі `#252526`,
  текст `#D4D4D4`. Палітра застосовується один раз до кольорів, шрифтів і
  растрових елементів стилю до створення кешів масштабування; вихідний VSF
  залишається незміненим. Графік швидкості, карта блоків і індикатор диска
  отримують кольори активної палітри через `Ot.Appearance.ThemeColor`.
- Стиль додається до ресурсу головного EXE на звичайному етапі PreBuildEvent;
  його початковий файл та походження — `resources/styles`.

Перевірки: `OtUiSmoke` перемикає темну/світлу теми через обидва елементи
керування, перевіряє палітру й читання збереженого вибору з INI та знімає
форми головного вікна й налаштувань. Результати та PNG — у `build`.
Ручна оцінка вигляду на Windows 7 та різних DPI залишається окремою перевіркою.
