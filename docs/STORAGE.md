# Зберігання Only Torrent

Починаючи з 0.3.1 застосунок не використовує INI, SQLite або FireDAC і не імпортує їх автоматично.

- `%APPDATA%/Only Torrent/settings.json`: конфігурація, мова, оформлення, ліміти, десять останніх папок.
- `Tasks/<ID>.json`: окремий опис задачі, стабільний додатний Int64 ID незалежний від info-hash; JSON-параметри файлів і посилання на resume.
- `Resume/<ID>.<GUID>.resume`: незмінні бінарні покоління fast-resume без Base64.
- Налаштовувана папка `Torrents/<info-hash>.torrent`: службові torrent-файли.
- `Languages/*.json`: мовні каталоги.

JSON містить schemaVersion=1. Профіль заблокований profile.lock. TOtTaskStore зберігає API; усі операції задач послідовно виконує TOtStoreWorker. Flush — бар’єр черги. Синхронні зміни підтверджуються після запису, resume пишеться асинхронно.

Запис: тимчасовий файл у тій самій папці, FlushFileBuffers, MoveFileEx з WRITE_THROUGH. Перед заміною JSON попередній читабельний опис записується в .bak. Resume спочатку записується в нове покоління, потім публікується посилання в JSON. Прибираються лише покоління, на які не посилається основний або резервний опис. Атомарність між кількома задачами не гарантується.

Під час запуску пошкоджений опис відновлюється з .bak; непридатна задача пропускається з діагностикою, інші завантажуються. Відсутній resume означає повторну перевірку файлів рушієм. Для видалення спочатку записується <ID>.json.deleted, що перешкоджає відновленню задачі з резервної копії після збою. Tombstone залишається; його розмір нуль байтів. Завантажені файли не видаляються сховищем.

Деінсталятор видаляє лише впізнавані службові файли профілю за явним вибором користувача; довільні файли та папки завантажень залишаються.

Вміст завантажень і partfile libtorrent належать обраній папці завантаження (save_path), а не профілю. Тимчасові JSON/resume-записи створюються поруч із кінцевими службовими файлами, для заміни в межах одного тому; це метадані, не копії завантажуваного вмісту. Resume може зростати з кількістю частин і незавершених блоків, але не містить самих блоків даних.
