# Dark VCL style

`Windows10Dark.vsf` is the unmodified Windows10Dark VCL style supplied with
RAD Studio 13 (Studio 37.0), from the shared Documents/Embarcadero/Studio/37.0/Styles
directory. It is an Embarcadero asset, not original Only Torrent artwork; its
use and redistribution are governed by the RAD Studio license.

The main project's existing pre-build resource step embeds it as
`OT_DARK_THEME` in `build/Ot.Version.res`. No external style file or additional
runtime DLL is required. The light theme uses the Windows system style.
