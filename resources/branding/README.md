# Основний знак qsTorrent

Обрано варіант №4 «Рух» у синьому колі, запитаний колір фону `#2758A8`.

Затверджений оригінал: `concepts/qs-04-motion-circle-2758a8.png`.
Іконка застосунку: `../qstorrent.ico`, розміри 16, 20, 24, 32, 40, 48, 64, 128 і 256 px із прозорістю.

ICO вбудовується як `MAINICON`; його використовують EXE та стандартний механізм VCL Application.Icon. PNG та Pillow під час звичайного Delphi-збирання не потрібні. Необов’язкове повторне створення ICO: `python tools/make-app-icon.py`.

Усі інші зразки залишаються в `concepts`.
