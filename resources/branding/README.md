# Основний знак Only Torrent

Поточний знак — білі стилізовані літери OT у синьому колі з фоном `#2758A8`, прозорість поза колом. Стиль продовжує раніше обраний варіант №4 «Рух».

Поточний оригінал: `ot-logo-circle-2758a8.png`.
Іконка застосунку: `../otorrent.ico`, розміри 16, 20, 24, 32, 40, 48, 64, 128 і 256 px із прозорістю.

Розміри до 128 px зберігаються як стандартні 32-бітні DIB-кадри для системних списків; 256 px — стиснений PNG. Головне та службове вікна VCL явно отримують велику й малу іконки, зокрема іконки класів вікон.

ICO вбудовується як `MAINICON`; його використовують EXE та стандартний механізм VCL Application.Icon. PNG та Pillow під час звичайного Delphi-збирання не потрібні. Необов’язкове повторне створення ICO: `python tools/make-app-icon.py`.

Усі попередні зразки QS залишаються в `concepts`, включно з `qs-original-app.ico`. Вони є історією дизайну та не вбудовуються в Only Torrent.
